## 1. 스택과 호출

`push rbx`는 레지스터 값 자체를 저장하며, `[rbx]`의 메모리 내용을 읽는 것과 다르다. `push`와 `call`은 각각 rsp를 8 감소시키고 값·복귀 주소를 저장한다. 일반적인 `ret`은 `[rsp]`를 rip에 넣고 rsp를 8 증가시키며, `pop rbx`는 저장된 값을 복원한다.

별도 어셈블리 계측 실행에서 기준 rsp 대비 push 후 -8, helper 진입 -16, 지역 공간 16바이트 확보 후 -32를 확인했다. 지역 공간 확보 후 복귀 주소는 `[rsp+16]`에 있었다. helper 복귀 후 rbx=88, pop 후 rbx=55와 원래 rsp가 복원됐다. 스택·저장값·복귀 주소·정렬 검사 모두 PASS, 실행 exit 0. GDB 관찰은 아니다.

## 2. ELF와 주소 대응

섹션은 코드·데이터·디버깅 정보 등 용도별 구분이다. `PT_LOAD`는 적재할 파일 범위·가상주소·파일/메모리 크기·권한을 지정하며 여러 섹션을 포함할 수 있다. 실제 파일에서 `.debug_info`는 섹션 목록에 있지만 적재 세그먼트 대응표에는 없었다.

파일 오프셋은 파일 시작 기준 위치, ELF 가상주소는 ELF가 지정한 메모리 배치 위치다. 파일에서 가져오는 범위 안에서는 다음으로 대응한다.

```text
파일 위치 = LOAD.Offset + (찾는 ELF 가상주소 - LOAD.VirtAddr)
실제 사례: 0x2db0 + (0x3dc0 - 0x3db0) = 0x2dc0
```

해당 파일 바이트와 `readelf -x .dynamic`의 16바이트가 일치했다. 이는 파일 기반 정적 대조다. `MemSiz`는 메모리 전체 크기이며, `FileSiz`를 초과하는 부분은 처음에 0으로 채워진다. 크기가 N이면 유효 위치는 0부터 N-1까지다.

## 3. 실행 중 메모리 확인

자체 `mapping_probe`가 프로그램 헤더·로드 기준 주소와 실행 중 배열을 직접 읽고 `/proc/self/exe`의 바이트와 비교했다.

| 항목 | 첫 실행 | 재실행 |
|---|---|---|
| marker ELF 가상주소 | 0x4010 | 0x4010 |
| 파일 오프셋 | 0x3010 | 0x3010 |
| 실행 주소 | 0x55a79eebf010 | 0x55979b02a010 |
| 초기 첫 바이트 | 41 | 41 |

초기 8바이트는 파일·메모리가 일치했다. 메모리 첫 바이트를 5a로 바꾼 뒤에도 파일 재읽기는 41이었다. 별도 전역 배열 16바이트의 초기 0도 확인했다. 두 실행 모두 exit 0. PIE는 재배치 가능한 실행 파일 형식이고 ASLR은 배치 주소 무작위화다. 같은 바이너리 내부 주소 차이는 유지되지만 실행 파일 main과 libc puts에 같은 기준 주소를 적용할 수는 없다.

`_start`의 정적 분석에서는 `lea rdi,[rip+0xca]`가 다음 명령 주소 0x107f를 기준으로 main의 ELF 주소 0x1149를 준비하고 `__libc_start_main`을 호출함을 확인했다. main 호출 자체의 동적 추적은 아니다.

## 4. 파서·ASan 복습

복사 전 필요한 조건은 `input_size >= 7`, `length <= input_size - 7`, `length <= sizeof(payload)`다. 길이가 정확히 같아도 허용하며, 빈 본문·length 0도 세 크기 조건을 만족할 수 있다. 복사 후 출력 길이 제한은 앞선 범위 밖 쓰기를 막지 못한다.

기존 Day114 실제 보고서의 `WRITE of size 20`, `[32,48) payload`와 memcpy 소스를 대조했다. 목적지 크기는 16바이트이고 목적지 처음부터 20바이트를 쓰는 작업은 4바이트 초과다. 작업 크기만으로 초과량을 단정하지 않고 시작 위치·객체 범위를 함께 확인한다. 오늘 새 ASan 실행은 하지 않았다.

## 5. 교정·기록 상태

call의 rsp 감소, 레지스터 값과 역참조, FileSiz와 MemSiz의 전체/추가분, 끝 경계 제외, 원본/목적지 검사 부등호, 서로 다른 모듈의 기준 주소를 도움받아 교정했다. 이후 조건 변경 문답에서 해당 차이를 재확인했다. 전체 학습을 무힌트로 수행했다고 기록하지 않는다.

실험 소스와 원자료는 이 문서와 같은 폴더에 있다. 주요 명령은 `cc -std=c11 -Wall -Wextra -Werror -O0 -g`(mapping_probe는 `-fPIE -pie` 추가), `file`, `readelf -hW/-lW/-SW`, `readelf -x .dynamic`, `objdump -d -Mintel --disassemble=_start`, `nm -n`이다. 기존 근거: `Day101-160/Day114/asan_report.txt`, `day114_parser.c`.
