## 오늘의 메인: 힌트 없이 먼저 조사
새 바이너리의 동적 심볼, PLT와 GOT 슬롯, relocation 항목을 조사한다. 최소 **서로 다른 외부 함수 2개**에 대해 다음을 구별하여 자신만의 표 작성:
- 정적 ELF 오프셋과 실제 실행 중 절대주소
- 코드의 PLT 호출 지점과 GOT 슬롯
- 외부 함수 호출 전/후 GOT 슬롯 값(관찰 가능할 경우), 그 값이 속한 이미지/매핑
- 실제 libc 매핑과 해당 함수 주소 사이의 검증 가능한 관계
- 확정한 관찰 / 잠정 가설 / 확인 불가 내용을 분리

분석에 필요한 도구와 순서는 학생이 우선 선택한다. 별도 도구 해설/정답 없이 시작해서 명령·출력 원문을 저장한다. GDB에서 관찰한 결과와 정적 역어셈블을 최소 두 독립 근거로 교차 확인한다. 각 관찰 전 예상, 실제 결과, 틀린 예상과 수정 이유, 새로운 반례 조건 하나를 남긴다.
