# Day101 — Anti-debug 정적 패치

바이너리는 `ptrace(PTRACE_TRACEME)`가 `-1`을 반환하면 anti-debug 함수가 `1`을 반환하고, main에서 `TEST EAX,EAX → JNZ`를 통해 실패 경로로 이동한다.

실패 분기 주소 `0x1336`은 실행 가능한 LOAD 세그먼트에 포함된다.

```text
file_offset = 0x1336 - 0x1000 + 0x1000
            = 0x1336
```

원본 분기 명령의 6바이트를 같은 길이의 NOP로 변경했다.

```text
원본: 0f 85 8c 00 00 00
패치: 90 90 90 90 90 90
```

패치본을 GDB에서 실행했을 때 anti-debug 함수는 여전히 `EAX=1`을 반환했지만, 실패 분기가 제거되어 Token 입력까지 진행했다. GDB를 재실행해도 우회가 유지됐다.

```text
원본 SHA-256:
28e890295425379ce96d41e5dc14559e18acedc8f615c38b5d5dfbc7c8c6fefe

패치본 SHA-256:
e78fcfee9f71de0991494be6db02cdf00f9edf56a06e6bde4012e76e5d437f03
```

동적 레지스터 변경은 현재 실행에만 적용되지만, 정적 패치는 파일 자체를 변경하므로 재실행 후에도 유지된다. 대신 파일 해시가 달라져 코드 서명이나 무결성 검사에 탐지될 수 있다.
