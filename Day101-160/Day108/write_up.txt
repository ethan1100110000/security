# Day108 - IOC 분석 노트

`day107_static_lab`을 대상으로 정적 분석을 수행했다. SHA-256은 `f0d2c87e825606f0cb1abba441691107dc5ae91fdbfbfe7d418f63bdef52925f`이며, 동일한 샘플을 식별하는 IOC로 사용할 수 있다.

정상 실행 흐름에서 사용자가 `archive`를 선택하면 `/tmp/day107_status.log`를 생성하거나 덮어쓰고 `analysis_status=ready\n`을 기록한다. 따라서 파일 경로와 기록 문자열은 조건부 IOC로 판단했다.

`198.51.100.20:4444`, `/bin/sh`, `execve` 관련 코드는 main에서 도달하지 않는 함수에 존재한다. 네트워크 함수는 소켓을 닫은 뒤 `-1`을 사용하며, `/bin/sh`는 출력 문자열일 뿐이므로 실제 네트워크 통신이나 셸 실행 행위로 판단하지 않았다.

이번 분석은 정적 분석이므로 파일 생성과 기록의 실제 성공 여부, 실행 환경에 따른 추가 동작은 확인하지 못했다.
