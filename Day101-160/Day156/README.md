# Day156 / FINAL W06 4/4 — 블라인드 스택 분석 종합평가 (진행 중)

## 시험 자료
- 교사가 제작한 Linux x86-64 ELF `day156_target.elf`는 채팅 첨부 파일로 제공. 소스는 최초 독립 분석 종료 전 공개하지 않는다.
- SHA256: `616ff0a7e73176034294a9c3997c4d070a005a11d515417fbf59050e02a5f848`
- 로컬 격리 학습 대상. 교사 환경에서 정상/오류 입력의 동작을 사전 확인했으며, 사용자 실험 증거와 구분한다.
- 평가 목적은 취약점 원인과 메모리 안전성, 완화기법의 한계, 수정 원리의 검증이다. 셸 획득 등은 요구하지 않는다.

## 독립 심사
1. 입력 형식 및 유효성 검사와 처리 흐름을 복원.
2. 메모리 객체 경계와 입력의 영향 범위를 검증. 어떤 입력에서 어떤 현상이 실제로 나타나는지 확인.
3. 보호기법 확인 후 관찰된 동작/오류의 원인을 설명.
4. 코드와 런타임/메모리 근거 2종 이상 확보, 정상 입력과 경계 반례 비교.
5. 수정 방안과 회귀 테스트 제안. 가설/관찰/미확정 사항을 구분해 10분 분량의 분석 발표.
- 허용: file, checksec, readelf, objdump, Ghidra, GDB, Python 등 로컬 분석 도구. 정답/소스 열람 없이 독립적으로 수행.
- 교사 힌트가 필요하면 사용 사실 기록하고 다른 조건에서 무힌트 재검증.

## Git 배포 (2026-11-19)
- ELF 실행 파일을 Git에서 바로 재생성하도록 **무손실 압축된 바이너리**를 `day156_target.elf.xz.b64`에 올리고 `unpack.sh`를 추가했다. 원본 C 소스나 해답은 공개하지 않았다.
- WSL: `git pull --ff-only && cd Day101-160/Day156 && bash unpack.sh && ./day156_target.elf`
- `unpack.sh`는 Base64→xz 압축 해제 후 ELF를 복원하고, 위 SHA256과 일치하는지 자동 검증하고 실행 권한을 부여한다. 저장소에 인코딩 형태로 들어 있는 것은 **바이너리를 완전 복원하기 위한 배포 형식**이지 문제를 새로 컴파일하는 소스가 아님.
- 사용자 독립 분석 결과 제출 전. Day156 평가 아직 미완료.
