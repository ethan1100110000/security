## 2026-11-24 — 빌드 환경 호환성 수정
- 최초 ELF는 교사 빌드 환경 glibc 2.41 헤더의 `__isoc23_strtol@GLIBC_2.38`에 의존하여 사용자 WSL Ubuntu glibc 2.35에서 로더 오류 발생. 이는 **사용자의 분석 오류가 아닌 교사 실습물 호환성 문제**다.
- 기존 프로그램과 각 명령 1~5의 관찰 동작은 유지하면서 `strtol@GLIBC_2.2.5`를 참조하도록 수정 빌드. 재컴파일 및 `readelf --version-info` 확인 결과 필요한 최고 버전은 GLIBC_2.34. 교사 컨테이너에서 정상 입력 실행 확인. 사용자 WSL2 환경 실측은 아직 확인 전.
- 동일 파일명으로 인코딩된 ELF와 `unpack.sh` 검증 해시를 갱신; 이전 빌드와 해시는 Git history에 보존. `git pull --ff-only` 후 반드시 `bash unpack.sh` 재실행해 이전 복원 ELF를 덮어써야 함.
