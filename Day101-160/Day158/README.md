## 메인: first pass (최초 제출 전에 해설 없이)
- 프로그램의 서로 다른 관찰 출력(숫자/주소처럼 보이는 값/문자열)을 구분한다.
- **각 관찰을 보자마자 base를 계산하지 말고** 이것이 주소인지, 어느 이미지에 속한다고 주장할 수 있는지, 상위 비트 정보가 충분한지, 같은 프로세스/다른 프로세스에서 어떻게 검증할지 가설을 적는다.
- 서로 다른 실행 3회 이상 비교한 원본 출력과 최소 2가지 도구(ELF 분석, GDB vmmap/메모리 등)의 독립 근거를 연결한다.
- PIE base/libc base 추론에서 잘못된 가정을 깨뜨리는 **반례 3개**: 외형만 주소, 일부 하위 비트만 노출, 잘못된 심볼/이미지 오프셋 등으로 서로 다른 실패 메커니즘을 설명한다.
- 정확히 재현 가능한 값(ASLR로 매번 바뀌는 절대주소 제외)은 입력, 계산, 오류 및 반례와 함께 Git에 기록한다.
