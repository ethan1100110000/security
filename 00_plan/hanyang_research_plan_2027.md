# 한양대 SSLab 준비 계획 (2026-10-05 적용)

## 적용 기준

- 계획 기간: 2026-10-05~2027-04-30, 30주. 날짜는 목표이며 실제 진도는 `progress_log.md`에서 확인한다.
- 시간: 평일 메인 120분 + CS 30분 + 보안 전반 2회독 30분. 주 5일 약 15시간. 자격증 공부·휴식은 별도이며 주말 필수 공부는 없다.
- 목표: 바이너리 분석·퍼징 기초, 논문 이해, 자체 코드 비교 실험, 독립적인 설명 능력과 지원 자료를 준비한다.
- 기준 파일: [`hanyang-research-plan-2027.xlsx`](hanyang-research-plan-2027.xlsx). 이 문서의 주간 표는 해당 파일과 같은 내용이다.
- 기존 `보안 계획표.xlsx`는 이전 Day 계획 참고용이다. 새 계획과 충돌하면 현재 계획을 따른다.
- 계획 전환 시점의 마지막 완료 Day129에서 이어가며 첫 정규 학습은 Day130 / W01이다. 기존 완료 기록을 새 주차에 맞춰 다시 완료 처리하지 않는다.

## 운영과 도달 기준

- 메인: 질문·가설을 먼저 세우고 근거 확인, 자체 코드 관찰·검증, 비교·반례 검토, 결과·한계 설명 순으로 진행한다. 영어 논문 읽기는 메인 시간에 포함한다.
- CS: 5분 회상, 15분 개념·예제, 10분 설명을 기준으로 한다. 정의·예제·조건 변경 질문에 답할 수 있는지 확인한다.
- 2회독: 5분 회상, 20분 기존 기록 대조·관찰, 5분 재설명. [상세 규칙](review_rules.md)을 따른다.
- 실제 학습·시간·답변·약점은 Git 로그에 기록한다. 엑셀은 실행 계획만 유지한다.
- 2주 연속 지연되면 핵심 논문 2편과 대표 과제 1개를 유지하고 선택 논문·실험 조건 수를 줄인다.

## 핵심 논문과 대표 과제

- AIMFuzz (2024): 함수 단위 바이너리 퍼징의 문제·설계·평가·한계 이해. W06~W07에 집중한다.
- BASTAG (2025): 메모리 접근 제어의 보호 목표와 비용 평가 이해. W10~W11에 집중한다.
- Semi-Virtual Addressing (2026): 최근 연구의 문제와 구조 지식 확인. W12~W13 여유 시 선택 읽기다.
- 대표 과제 후보: 자체 코드의 상태 초기화 방식이 반복 테스트의 결과 일관성과 실행 비용에 주는 영향.
- W13 예비 검토 후 연구 질문 1개를 확정한다. 논문 전체 재현·새 취약점 발견을 필수 완료 조건으로 두지 않는다.
- 범위 검사와 권한 검사는 보호 목표가 다르므로 같은 보장을 제공하는 방법으로 취급해 속도만 비교하지 않는다.
- 3월 말까지 코드·실행법·원자료·보고서·CV·연구계획서 초안을 연결한다. 보고서는 8~12쪽을 목표로 필요한 내용을 담는다.

공식 연구 목록: https://sslab.hanyang.ac.kr/publications

BASTAG 저자 공개 원문: https://junseungyou.github.io/assets/bastag.pdf

공개 논문과 2027년 실제 모집 주제는 구분한다. 12~1월에 이해와 예비 결과를 바탕으로 문의 자료를 준비하고, 발송은 사용자 요청에 따라 진행한다.
