# Security Second-Pass Review Rules

2026-10-05부터 [현재 준비 계획](hanyang_research_plan_2027.md)에 적용한다.

## 시간과 범위

- 평일 30분을 기준으로 이전 보안 학습 전체를 2회독한다.
- pwn만 반복하지 않고 리눅스·어셈블리·호출 규약·ELF·디버깅·메모리 오류·보호 기법·리버싱·퍼징·보고서 읽기를 순환한다.
- 실제로 공부한 내용은 이전 Day와 Git 기록으로 확인한다. 미학습 주제는 복습 완료로 처리하지 않는다.
- 현재 계획표의 복습 주제를 기본으로 하되, 회상이 약한 이전 주제를 먼저 보완한다.

## 30분 진행

1. 5분: 기존 답과 노트를 보지 않고 개념·예상 동작·이유를 설명한다.
2. 20분: 이전 문서와 관찰 자료를 대조한다. 필요한 경우 자체 코드의 정상 동작·상태를 관찰한다.
3. 5분: 틀린 이유, 교정한 개념, 다음에 확인할 질문을 자신의 말로 설명한다.

요일 운영:
- 월: 이번 주 주제를 먼저 회상한다.
- 화: 기존 노트와 대조해 빈칸을 확인한다.
- 수: 이전 관찰 결과를 근거로 설명을 복원한다.
- 목: 관련 주제의 공통점·차이·한계를 비교한다.
- 금: 이번 주 설명과 함께 지난주·4주 전 약점을 짧게 재확인한다.

## 교사 역할과 완료 기준

- 사용자가 먼저 답한다. ChatGPT는 질문·반례·힌트를 통해 스스로 수정하도록 돕는다.
- 답변 후 보충은 틀린 핵심과 빠진 핵심에 집중한다. 자세한 설명이 필요하면 분량을 늘린다.
- 정의를 말하고 예제나 그림을 설명하며 조건이 바뀐 질문에 답할 수 있는지 확인한다.
- 기억이 약하면 새 문제 수를 늘리지 않고 같은 원리를 다른 예제로 다시 확인한다.
- 실제 복습 주제·참고 Day·답변·남은 약점은 `progress_log.md`에 기록한다. 엑셀에는 학습 로그를 쓰지 않는다.
