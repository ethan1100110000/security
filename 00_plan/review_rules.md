# Daily Review Rules

- 매일 본 학습과 CS가 끝난 뒤 10~20분 복습을 진행한다.
- 복습 주제는 오래된 항목과 무작위 항목을 섞되, 1~2회만 다룬 약한 주제를 우선한다.
- 우선 복습 대상 예시: GOT overwrite, shellcode, stack pivot, FSB write, ret2libc, PIE/canary leak 검증.
- 기본 형식은 짧은 질문 3개 또는 작은 실전 추적 문제 1개다.
- 사용자가 먼저 답하고, ChatGPT는 틀린 핵심과 빠진 핵심만 3~5줄로 보충한다.
- 사용자가 자세한 설명을 요청하지 않는 한 장황한 재설명과 이미 맞은 내용의 반복은 하지 않는다.
