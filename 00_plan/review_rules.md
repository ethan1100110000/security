## 복습

- pwn에 한정하지 않고 리눅스·어셈블리·호출 규약·ELF·디버깅·메모리 오류·보호 기법·리버싱·퍼징·논문을 순환한다.
- 해당 Day의 복습 과제와 실제 이전 Git 기록을 대조한다. 회상 → 근거 확인·필요한 관찰 → 조건 변경·재설명 순서다.
- 5/20/5분은 배분 참고값이다. 시간을 재거나 맞추기 위해 문제를 추가하지 않는다.
- 처음에는 노트 없이 설명하고 막히는 지점만 보완한다. 도움받은 오답은 다른 조건으로 확인한다. 재검증한 뒤 같은 종합 발표를 반복시키지 않는다.
- 월: 주제 회상 / 화: 기록 대조 / 수: 관찰 근거 설명 / 목: 공통점·차이·한계 / 금: 주간·이전 약점 확인을 참고한다.
- 참고 Day·답변·도움·오답·재검증 결과와 남은 약점은 progress_log.md에 기록한다.

## 교사와 AI 사용

- 사용자가 먼저 현상·가설·분석 계획·필요한 증거를 말한다. AI는 질문·반례·단계적 힌트로 검토하며 주장에 자동 동의하지 않는다.
- AI 출력은 가설로 취급한다. 소스/Ghidra 해석은 objdump·GDB·메모리·sanitizer·입력 결과 등 해당 주장에 맞는 증거로 확인한다.
- 정적 읽기, 손 추적, 별도 계측 실행, 실제 대상의 동적 관찰을 구분한다. 소형 실험 결과를 기존 대상의 직접 관찰로 바꾸어 기록하지 않는다.
- 최초 독립 답변과 힌트 후 교정·조건 변경 재검증을 구분한다. 이해를 확인한 원리는 단순 반복 대신 다음 과제에 적용한다.
- 막힌 도구는 이유와 해결 조건을 적는다. 요구된 실제 검증을 수행하지 않았다면 계획상 완료한 것으로 기록하지 않는다.
